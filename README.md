# dotfiles
Nate's Dotfiles

Featuring:
- Neovim Config
- Tmux Config
- Alacritty Config
- Bootstrapping Script for Symlinks

## Setup

For my future reference, clone the repo and

```
./bootstrap
```

will symbolic link everything to where it needs to be.

### Also Needed
- you will need to `leader + I` inside tmux to get it to install plugins via tpm and reload
- you will need the Hack nerd font installed
